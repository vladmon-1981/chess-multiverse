# ♟ Шахматы: Мультивселенная

Полнофункциональное веб-приложение классических шахмат с поддержкой трёх визуальных тем, игры против ИИ и живого соперника.

## Возможности

- **Два режима игры:**
  - 👥 **Игрок vs Игрок** — локальная игра за одним устройством
  - 🤖 **Игрок vs Компьютер** — игра против ИИ с тремя уровнями сложности

- **Три визуальные темы:**
  - ♞ **Классические шахматы** — стандартные фигуры Стаунтон
  - 🐕 **Animal Hospital** — персонажи медицинской тематики
  - 🚗 **Тачки** — гоночные машины и персонажи

- **Универсальное управление:**
  - 🖱️ **ПК (мышь)** — Drag-and-Drop и клик по фигурам
  - 📱 **Сенсорные устройства** — тап-выбор с подсветкой допустимых ходов

- **Полная шахматная логика:**
  - Валидация всех ходов (включая рокировку и взятие на проходе)
  - Определение шаха, мата и пата
  - История ходов
  - Функция отмены хода

## Технологии

- **HTML5** — семантическая разметка
- **CSS3 + Tailwind CSS** — адаптивная верстка
- **JavaScript (ES6+)** — логика приложения
- **chess.js** — движок для валидации ходов и проверки позиций
- **Web Audio API** — динамические звуковые эффекты

## Быстрый старт

### Локально

1. **Клонируйте или скачайте проект:**
   ```bash
   git clone <ваш-репозиторий>
   cd chess
   ```

2. **Откройте в браузере:**
   ```bash
   # На macOS:
   open index.html
   
   # На Linux:
   firefox index.html
   
   # Или просто откройте вручную в браузере
   ```

3. **Играйте!**
   - Введите своё имя на главном меню
   - Выберите тему и режим игры
   - Нажимайте на фигуры и делайте ходы

### На сервере

Положите папку `chess` в веб-корень (например, `/var/www/html/chess`):

```bash
cd /var/www/html
cp -r /root/chess .
# Откройте http://ваш-сервер/chess/ в браузере
```

## Управление

### Настольный компьютер (мышь)

1. **Выбор фигуры:** Клик по фигуре — подсвечены все допустимые ходы
2. **Совершение хода:** Клик на подсвеченное поле
3. **Отмена выбора:** Клик на другую свою фигуру или пустое поле

### Сенсорное устройство (планшет, телефон)

1. **Выбор фигуры:** Тап по фигуре — она "приподнимается", подсвечены допустимые ходы точками
2. **Совершение хода:** Тап на подсвеченное поле
3. **Смена выбора:** Тап на другую фигуру
4. **Отмена:** Тап вне подсвеченных полей

## Уровни сложности ИИ

- **🟢 Лёгкий** — случайные и полусмысленные ходы (глубина поиска 1 ход)
- **🟡 Средний** — разумная стратегия, заметно сильнее (глубина 3 хода)
- **🔴 Тяжёлый** — серьёзный противник, продвинутая оценка позиции (глубина 5 ходов)

## Функции в игре

| Функция | Описание |
|---------|---------|
| **Отменить** | Отмена последнего хода (в PvE отменяет пару: ваш ход + ход компьютера) |
| **Новая игра** | Сброс доски, старт с начальной позиции |
| **В меню** | Возврат на главный экран (текущая игра теряется) |

## Сохранение прогресса

Приложение автоматически сохраняет в localStorage:
- 💾 Ваше имя (восстанавливается при следующем входе)
- 🎨 Выбранную тему

История ходов текущей партии хранится в памяти и теряется при перезагрузке или выходе в меню.

## Архитектура

### ChessApp (главный класс)
Управляет логикой игры, состоянием UI, событиями пользователя.

### ChessAI
Minimax-алгоритм с альфа-бета отсечением для выбора лучшего хода компьютера.

### ThemeManager
Переключение между 3 темами: символы фигур, звуки, визуальный стиль.

### SoundManager
Генерирует звуковые эффекты через Web Audio API (не требует внешних аудиофайлов).
