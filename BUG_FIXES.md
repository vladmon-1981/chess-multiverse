# Исправленные баги в "Шахматы: Мультивселенная"

## Баг 1: Тема не выбирается ❌ → ✅

**Проблема:** Кликовать на кнопки выбора темы ("Классика", "Animal", "Тачки") не удавалось — кнопки не реагировали на клики.

**Причина:** В файле `js/chess-app.js` строка 39 использовала неправильный селектор события:
```javascript
btn.addEventListener('click', (e) => this.selectTheme(e.target.dataset.theme));
```

Проблема в том, что `e.target` может быть не самой кнопкой, а вложенным текстовым элементом. Если клик попадает на текст внутри кнопки, `e.target` указывает на текстовый узел, у которого нет атрибута `data-theme`.

**Решение:** Изменено на прямое использование `btn.dataset.theme`:
```javascript
btn.addEventListener('click', () => this.selectTheme(btn.dataset.theme));
```

Теперь при клике на кнопку темы корректно передаётся значение `data-theme` атрибута.

## Баг 2: Не открывается меню выбора уровня сложности ❌ → ✅

**Проблема:** После нажатия кнопки "🤖 Игрок vs Компьютер" страница не переходила на экран выбора уровня сложности (Лёгкий, Средний, Тяжёлый).

**Причина:** Та же проблема в строке 43:
```javascript
btn.addEventListener('click', (e) => this.startGame('pve', e.target.dataset.difficulty));
```

**Решение:** Изменено на:
```javascript
btn.addEventListener('click', () => this.startGame('pve', btn.dataset.difficulty));
```

Теперь при клике на кнопку уровня сложности корректно передаётся значение `data-difficulty` атрибута.

## Дополнительная информация

### Как запустить

1. Откройте HTML-файл в браузере через HTTP-сервер (не через `file://`):
   ```bash
   cd chess-multiverse
   python3 -m http.server 8001
   # Откройте http://localhost:8001/index.html
   ```

2. На первой странице:
   - Выберите имя игрока
   - Выберите тему (классика, животные, машины)
   - Выберите режим (игрок vs игрок или игрок vs компьютер)

3. Если выбран режим против компьютера, выберите уровень сложности (лёгкий, средний, тяжёлый)

### Почему нужен HTTP-сервер?

При открытии файла через `file://` протокол CDN скрипты (css/js) не загружаются из-за CORS ограничений. HTTP-сервер решает эту проблему.
