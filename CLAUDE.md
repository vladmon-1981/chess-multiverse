# Chess Multiverse 3D — правила проекта

## Запреты владельца
- **Чужие бренды не использовать** (23.10.2026): ни названий, ни имён персонажей, ни логотипов, номеров и надписей
  на моделях и текстурах, ни реплик из чужих произведений. Темы называются «Гонки» / Racing, «Ветклиника» /
  Vet Clinic, «Хоккей» / Hockey (вымышленные «Ледяные Лисы» и «Полярные Ястребы»). Новые имена, команды и эмблемы
  придумывать свои. Дизайн (цвета, модели, анимации, звуки) при этом сохранять.
- Внутренние ключи тем `cars`, `hospital`, `hockey` не переименовывать: по ним хранится выбор пользователя.
- Команда подписи — платная `646ZQ353UC` (решение владельца 28.10.2026, в `project.yml`). Bundle id
  `com.chessmultiverse.app` без решения владельца не менять. В симуляторе — по одной сборке и одному симулятору.

## Где что лежит
- Веб: `index.html`, `js/`, `css/`; iOS-обёртка `ios/ChessMultiverse3D` (WKWebView, веб копируется в бандл).
- App Store: `ios/ChessMultiverse3D/AppStore/README.md` (риски, чек-лист), `check_metadata.py`, `shoot.sh`.
- Тексты вселенных: `js/themes.js` (ru) и `js/i18n-en.js` (en); имена фигур — в `js/three/{cars,hospital,hockey}.js`.

## Мониторинг App Store
`python3 tools/asc_monitor.py [--notify]` — новые отзывы/краши по ключу ASC API (секреты в `.secrets.local/`, состояние в `.state/`). Ключ не перевыпускать и не коммитить; `.p8` скачивается один раз.

## Сетевая игра (Game Center, с 10.11.2026)
- Решение владельца: онлайн через Game Center, без своего сервера. Режим `online` в `js/chess-app.js`,
  транспорт `js/online.js`, натив `ios/.../GameCenter.swift` (мост WKWebView `gc`), право
  `com.apple.developer.game-center` в `ChessMultiverse3D.entitlements`.
- Партия — GKMatch на двоих; ходы/сдача/время/реванш — JSON (`hello`, `move`, `resign`, `timeout`, `flag`, `rematch`).
  Цвет — жребий в `hello`. Подбор только с тем же временем на ход (`playerGroup` = 30/60/120/300).
- Время на ход: своё вышло — сам признаёт поражение (`timeout`); у соперника вышло + 5 с запаса — `flag`.
  Если у победителя нечем матовать — ничья.
- Доска почёта: таблицы Game Center `chessgm.rating` и `chessgm.wins` (Classic, «Most Recent Score»).
  Рейтинг Эло считается на устройстве (`localStorage` `chess-online`), на новом устройстве подтягивается из таблиц.
- Проверка без Game Center: `index.html?gcmock=1&gcname=A` и вторая вкладка `...&gcname=B` в том же браузере —
  вкладки играют друг с другом через BroadcastChannel. В обычном браузере кнопка «Играть онлайн» скрыта.
- Симулятор на этой машине годится только для «собирается и не падает»; партию вдвоём проверять на двух
  устройствах с разными Apple ID (Sandbox).
- Грабля (11.11.2026): Game Center при начале партии перенастраивает звуковую сессию (под голосовой чат) —
  эффекты пропадали или звучали с опозданием (Web Audio на паузе, играл при следующем касании), диктор молчал.
  Лечение: `AudioKeeper` в `ContentView.swift` возвращает `.playback` после смены категории, прерываний,
  закрытия окон Game Center и шлёт игре событие `audio`; `SoundManager.play` будит контекст и не играет
  звук, если тот не проснулся за 350 мс.

## ChessGM Pro (с 12.11.2026)
- Решение владельца (12.11.2026): «Pro-версия, цена 199 рублей, ограничение для бесплатной версии одно
  единственное – 5 партий в день». Разовая покупка без подписки, `com.chessmultiverse.app.pro`
  (NON_CONSUMABLE, ASC id 6833811176, базовая страна RUS 199 ₽, остальные пересчитывает Apple).
- Считается каждая начатая партия любого режима (`allowGame` в `startGame`; «Заново» — тоже партия).
  Онлайн проверяется до поиска и до реванша, сама сетевая партия не блокируется. Счётчик —
  `localStorage` `chess-daily` (по местной дате), статус — `chess-pro` (кэш до ответа StoreKit).
- Натив `Store.swift` (StoreKit 2, мост `store`), веб `js/pro.js` (`CMPro`), экран `#proModal`.
  В обычном браузере покупки и ограничения нет; проверка в браузере — `index.html?promock=1`.

## Значки фигур (с 12.11.2026)
- В вселенных кроме классики над каждой фигурой — кружок с шахматным символом (`makeBadge` в
  `js/three/board3d.js`). В нашей сборке three.js нет `Sprite`: значок — плоскость, которую
  `onBeforeRender` поворачивает к камере; эффекты взятия пропускают объекты с `name === 'badge'`.
- Значок стоит на корпусе (72 % высоты), рисуется поверх всего (depthTest off). Висящий над фигурой
  значок владелец дважды забраковал как «не по центру» — не поднимать.
- Ракурс по умолчанию — низкий (`presetElevation` normal = база−16°), одинаковый в портрете и альбоме (просьба владельца 12.11).

## Диктор: записанный нейроголос (с 12.11.2026)
- Реплики диктора записаны бесплатным Piper (без интернета): ru — Ирина (женский) и Руслан (мужской),
  en — hfc_female / hfc_male. Файлы `voice/<lang>-<f|m>/<ключ>.m4a`, список — `voice/manifest.js`.
  Ключ — `Voice.key(Voice.clean(текст))` в `js/sounds.js`. Выбор «Диктор: Женский / Мужской» в настройках
  (`chess-voice-kind`, по умолчанию мужской). Нет записи фразы — говорит системный синтезатор.
- **Поменял или добавил реплику в `themes.js`/`i18n-en.js` — перезапиши:** в браузере подключить
  `tools/voice_phrases.js`, `voicePhrases()` → `phrases_<lang>.json`, затем `tools/gen_voice.py` (докладывает
  только новые). Иначе новая фраза пропадёт из записанного голоса (`speak` берёт только записанные варианты).
- Имя игрока не записывается: в pvp записанный диктор говорит `win` вместо `pvpWin`.
- Лицензия русских голосов Piper не выяснена до конца (часть обучена на данных «только некоммерческое»).

## Подпись и выгрузка (грабли)
- Xcode часто теряет вход («No Accounts»). Архив без владельца: `xcodebuild archive -allowProvisioningUpdates`
  с `-authenticationKeyPath/-authenticationKeyID/-authenticationKeyIssuerID` (ключ из `.secrets.local/asc.env`).
- Выгрузка ключом API: облачная подпись недоступна (роль App Manager → «Cloud signing permission error»).
  Работает ручная подпись: локальный «Apple Distribution (646ZQ353UC)» + профиль App Store
  «ChessGM AppStore GameCenter» (создан через API 10.11.2026, до 31.10.2027), ExportOptions `signingStyle manual`.
