## Как устроено приложение

- **WKWebView с локальными файлами.** `ContentView.swift` показывает `Web/index.html` из бандла. Фаза
  сборки «Copy Web Version» (в `project.pbxproj`, зеркало в `project.yml`) копирует `index.html`, `css/`,
  `js/` из корня репозитория в `.app/Web`. Любая правка веба попадает в iOS при следующей сборке.
- **Нативного игрового кода нет.** Папки `Scene3D/`, `Views/`, `ViewModels/`, `Models/`, `Sound/`,
  `Theme/` — старая SceneKit-версия (до 2.0): компилируется, но не запускается и не видна пользователю.
  Нативно работают только оболочка и мост `tts` (системный синтезатор речи `AVSpeechSynthesizer`),
  аудиосессия `.playback` (звук при беззвучном режиме, не глушит чужую музыку), скрытый индикатор «домой».
- **Интернет не нужен.** three.js r186 и chess.js лежат в `js/vendor/`, движок компьютера работает в Web
  Worker на устройстве. Из сети грузятся только **шрифты Google Fonts** (см. «Риски»); без сети —
  системные шрифты.
- iPhone: портрет. iPad: все ориентации, `UIRequiresFullScreen` (без Split View).

## Язык интерфейса

Русский + английский, по языку системы: `navigator.language` в вебе (в WKWebView это язык iOS):
ru/be/kk → русский, всё остальное → английский. `js/i18n.js` (выбор языка, `tr()`, склонения, перевод
статической разметки по тексту), `js/i18n-en.js` (словарь и тексты вселенных, включая реплики диктора и
хоккейного комментатора). Нативно: `InfoPlist.xcstrings` (имя под иконкой: «Chess 3D» / «Шахматы 3D»),
локализации `en` и `ru` объявлены в проекте. Нативных пользовательских строк в рабочем коде нет, поэтому
`Localizable.xcstrings` не заводился. Голос диктора на английском: системные голоса `en`
(мужской Daniel/Aaron/Arthur/Alex, женский Samantha/Ava/Allison/Nicky; иначе лучший доступный).
Проверено в симуляторе (`-AppleLanguages "(en)"`): обрезанного текста нет, снимки en-US ниже.

### Анкета App Privacy (предложение, решает владелец)

- **Data Not Collected.** Разработчик не собирает данные: нет серверов, аккаунтов, аналитики, рекламы, SDK.
  Имя игрока и настройки лежат в `localStorage` на устройстве.
- **Tracking: нет.** `PrivacyInfo.xcprivacy`: `NSPrivacyTracking=false`, собираемых типов данных нет,
  Required Reason API нет (нет `UserDefaults`, дат файлов, `systemUptime`, места на диске).
- **Оговорка про шрифты:** при запуске страница запрашивает CSS и шрифты у Google
  (`fonts.googleapis.com`, `fonts.gstatic.com`): Google видит IP и язык. Разработчик этих данных не
  получает, и формально «Data Not Collected» остаётся верным, но чище и безопаснее **положить шрифты в
  бандл** (в списке дел). `PRIVACY.md` честно упоминает запрос шрифтов.
- Export Compliance: `ITSAppUsesNonExemptEncryption=NO` (HTTPS к Google Fonts — стандартное
  освобождённое шифрование; своей криптографии нет).

## Оценка риска по 4.2 (Minimal Functionality / веб-обёртки)

**Риск: низкий–средний.** Рецензент увидит WKWebView и может отнести приложение к «repackaged website».
Что говорить и что на самом деле так:

- Это **не сайт в рамке**: нет ни одного сетевого URL, вся игра (HTML/JS/3D-модели/шахматный движок)
  лежит в бандле и работает офлайн. Ни навигации, ни ссылок, ни браузерных элементов.
- Это **игра** с собственным интерактивным 3D (WebGL, ~11 тыс. строк кода, четыре набора процедурных
  3D-моделей), собственным шахматным движком (альфа-бета, 3 уровня, в Web Worker), синтезом звука на
  устройстве и свободной камерой. Это не контент, который можно открыть в Safari как страницу.
- Нативное: системный синтезатор речи (`AVSpeechSynthesizer`, мост `tts`) для диктора с выбором голоса
  по полу и языку; аудиосессия `.playback`; значок, локализованное имя, Privacy Manifest; отключён
  зум/выделение/контекстное меню веба, игра ведёт себя как приложение.
- Слабое место: у игры есть онлайн-версия на GitHub Pages (та же самая). Рецензенту можно честно сказать:
  «приложение содержит собственную копию игры, работает без сети, использует нативный синтез речи».
- Что снизит риск ещё (не сделано, это уже разработка): **тактильный отклик** (`UIImpactFeedbackGenerator`
  через мост на ходы/взятия/мат), **сохранение партии** между запусками (сейчас партия теряется при выходе),
  Game Center/достижения, «Поделиться» результатом. Один-два пункта заметно усилят позицию.
- Убрать мёртвый SceneKit-код из таргета (см. ниже) — меньше путаницы и размер.
